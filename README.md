# Swiggy Sales Performance Analysis – Excel

## 📊 Project Overview

This project presents an interactive Excel dashboard designed to analyze Swiggy sales performance and extract meaningful business insights from food delivery data.

The analysis focuses on key business metrics such as sales performance, restaurant/cuisine trends, city-wise performance, and price-range analysis.

## 🎯 Objectives

* Analyze overall sales performance
* Identify high-performing cities and cuisines
* Analyze customer/order trends
* Compare performance across different price ranges
* Create meaningful KPIs for business performance
* Build an interactive Excel dashboard for data-driven insights
